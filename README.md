Entry for the [make.fun](https://make.fun) bounty **One Sentence for a Traveler from 1800** ($2, top 10 paid).

`main.ts` writes one sentence (177 characters) to `/output/entry.txt`, explaining the modern internet to a time traveler from 1800 using only things they already know: a library, a post office, a shop, a newspaper, and a box on a table that never sleeps.

> "It is a library the size of a city, a post office that answers in a breath, and every shop and newspaper in the world, all inside a box that sits on your table and never sleeps."
